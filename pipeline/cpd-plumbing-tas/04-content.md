# 04 — Extended content — /cpd-plumbing-tas

## The content is the page, not a separate draft

No separate long-form draft was written. Copy was authored directly into
`src/content/cpd-bundles/cpd-plumbing-tas.mdx`, which is the artefact of record for every word on the page.

This is a deviation from the pipeline's normal shape and is recorded rather than hidden. It is
workable here because the section structure was inherited (see 03) rather than designed, so there was
no intermediate stage at which briefs became prose.

**Where the copy loses coverage.** `system-health`'s capsule-match check compares answer capsules in
`04-content.md` against the built page. With the copy authored in place there is nothing to compare,
so this page will not appear in that check's OK list. That is a real loss of coverage and the reason
the normal shape exists.

Every capsule on the page was measured at 40-60 words. See 07.
