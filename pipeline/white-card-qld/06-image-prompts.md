# 06 · Image prompts — /white-card-qld

One slot: the `#session` ZSection. Register is **photographic** (confirmed 2 Aug 2026, see
`handover/HANDOVER-image-prompts-2026-08-02.md`) — this slot follows that house style, not the line-art
exception `/white-card-wa` shipped as an experiment.

**Compositional precedent: `/white-card-nsw` slot 8, not WA/TAS.** QLD's CRTD session, like NSW's
trainer-led virtual classroom, is a genuinely live, multi-person session — not self-paced study. A
learner alone at a laptop would misread as self-paced, which is precisely the claim this page must not
make (cond. 42 bans self-paced content outright). The trainer must be visible on screen alongside the
learner, same reasoning as the NSW brief.
